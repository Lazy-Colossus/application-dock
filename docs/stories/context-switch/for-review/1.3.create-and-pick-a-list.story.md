# Story 1.3: Create and pick a list

Status: Ready for Review

## Story

As a user,
I want to pick an existing list or create a new one when I open the app,
so that I can keep separate boards of todos.

## Acceptance Criteria

1. **Home shows my lists.** Given the Context-Switch home (`/context-switch`), when it loads, then it calls `GET /api/context-switch/lists` (scoped to me by the token) and shows my lists as selectable items, each with its name and a todo count (active count). (FR-2, FR-4)

2. **Empty state.** Given I have no lists yet, when the home loads, then it shows a calm empty state prompting me to create my first list (no error).

3. **Create a list.** Given the home, when I enter a name and create, then `POST /api/context-switch/lists` with `{ name }` persists a new list with a `l-{uuid8}` id (empty `todos`, a default `grid`) to my file, and I am navigated to that list's board `/context-switch/lists/:listId`. (FR-3)

4. **Open a list.** Given an existing list in the picker, when I select it, then I navigate to `/context-switch/lists/:listId`.

5. **Name validation.** Given a create with an empty/whitespace name, when submitted, then the client disables the submit control (no request), and the API also rejects a blank name with a `422`/`400` `{detail}` error as a backstop.

6. **List summaries only.** Given `GET /api/context-switch/lists`, when it responds, then it returns list summaries (`id`, `name`, `active_count`) — not the full todo payloads (the board fetches those in later stories).

## Dev Notes

**Store contract.** Follow the platform Pinia convention: expose `loading`/`error` refs; async actions use `try/finally`; errors go to `error.value`, never a bare `console.error`. All HTTP through `frontend/src/composables/useApi.ts` (it injects the `Authorization` header and throws `ApiError`). [Source: CLAUDE.md#Frontend]

**Auth scoping.** Router routes use `current_user: str = Depends(get_current_user)` and pass it into the service — unlike archery/shell which discard it as `_: str = Depends(...)`. This app *needs* the username to pick the file. [Source: Story 1.2 Dev Notes]

**API contract.** snake_case JSON, direct serialization (no `{data,status}` envelope), `{detail}` errors, ISO-8601. [Source: CLAUDE.md#Backend]

**Scope discipline.** Only list read/create + the picker UI here. Todo CRUD, the grid, and board rendering are Epic 2. `BoardPage.vue` is a placeholder in this story.
