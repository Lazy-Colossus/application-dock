# Story 1.1: Register Listies in the Application Dock shell

## Status

Ready for Review

## Story

**As** a user,
**I want** Listies to appear as an app in the dock and open to its own home,
**so that** I can launch it like any other app in the platform.

## Acceptance Criteria

1. **Shell card.** Given the dock landing page, when it renders the app registry, then a Listies card appears (label "Listies", icon `table_chart`) alongside the existing apps, and selecting it routes to `/listies`. (FR-1)

2. **Backend registry.** Given `GET /api/apps`, when called, then the response includes a Listies `AppDescriptor` (`id: "listies"`, `label: "Listies"`, `icon: "table_chart"`, `route: "/listies"`).

3. **Routes.** Given the router, when `/listies` is visited by a logged-in user, then `ListiesHomePage.vue` renders (lazy-loaded, `meta: { title: "Listies", requiresAuth: true }`); `/listies/sheets/:sheetId` is also registered and renders a placeholder `SheetPage.vue` that reads `:sheetId` (fleshed out in Epic 2).

4. **App module skeleton.** Given the new app, when the project is set up, then `frontend/src/apps/listies/` exists and is self-contained (the shell imports it only via `registry.ts`), and a backend `routers/listies.py` is mounted under `/api/listies` behind `Depends(get_current_user)` — even if it exposes nothing but a health-shaped placeholder until Story 1.3.

5. **Story folders.** Given the docs tree, when the app is registered, then `docs/stories/listies/for-review/` and `docs/stories/listies/done/` exist. (AR-1)

6. **No regressions.** Given the existing suites, when this story lands, then `pytest` and `npm test` stay green and `black`/`ruff`/ESLint/Prettier are clean on touched files.

## Dev Notes

**Two-file change.** Adding an app is meant to be registry + routes; `HomePage` iterates the registry and `AppCard` is generic — no other shell changes. [Source: CLAUDE.md#Adding a new app]

**Icon.** `table_chart` (Material Icons) reads as a grid of typed columns; the other apps use single thematic glyphs (`adjust`, `school`, `swap_horiz`).

**Auth.** Every Listies route sits behind `Depends(get_current_user)` from the start — unlike archery/shell, this app *uses* the username to pick its file (Story 1.2), so pass it into services rather than discarding it as `_`.

**Scope discipline.** No data model, no endpoints beyond the mounted router, no grid. Pages are placeholders.
