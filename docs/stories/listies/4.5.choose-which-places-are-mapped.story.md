# Story 4.5: Choose which places are on the map

## Status

Draft

## Story

**As** a user,
**I want** to tick and untick which places are currently plotted,
**so that** I can narrow the map to the handful I am actually deciding between.

## Acceptance Criteria

1. **The checkbox column.** Given the map pane is open, when the grid renders, then it grows a leading "on map" checkbox column with one tick per row holding at least one non-empty place; rows with no place have no checkbox. (FR-18)

2. **All on by default.** Given the pane opens, when it first renders, then every place row is ticked.

3. **Instant effect.** Given a ticked row, when I untick it, then its marker disappears immediately, and re-ticking restores it — no request is made either way. (FR-18)

4. **All / none and a counter.** Given the pane header, when it renders, then it offers **all** and **none** controls and a "4 of 7 shown" counter that tracks the ticks.

5. **No jumping.** Given a tick change, when the markers update, then the map does **not** re-fit its bounds; an explicit "fit to shown" control re-fits on demand.

6. **View state only.** Given the ticks, when I switch tab, reload, or close the pane, then they reset to all-on — like sorting, this is never written to the file.

7. **Closed pane, clean grid.** Given the map pane is closed, when the grid renders, then the checkbox column is gone and the grid is back to full width.

8. **New rows.** Given a place added to a row while the pane is open, when it appears, then that row is ticked by default and its marker is plotted.

## Dev Notes

**View state, like sorting.** Ticks are how the map is being read right now, not a property of the data — so they live in the store, never in the file, and reset with the tab. This mirrors the sort decision in Story 2.6 and keeps the document free of UI state. [Source: Story 2.6, FR-18]

**Don't fight the cell focus model.** The checkbox column sits outside the cell grid: Tab within the grid must still walk cells (Story 2.3), while the checkbox stays reachable in the normal document order.

**Bounds are user-controlled.** Auto-fitting on every tick makes the map lurch while you triage; fitting stays on the open and the explicit control. [Source: Story 4.4 AC 11]
