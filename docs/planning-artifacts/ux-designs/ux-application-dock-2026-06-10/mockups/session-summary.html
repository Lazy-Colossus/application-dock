The filter IS the button

Tallies are multi-select — any combination. Selecting re-scopes both the list and the primary action, so the learner never reconciles "what's shown" against "what will run".

Nothing selected → "Practice Again", no number: it replays the whole session, and naming no count keeps it from being misread as a subset. Select Close + Incorrect → "Practice these 8 again ✦".

Grade reads as a word, not a hue

The accessibility floor is explicit: "grade outcome carries its meaning in the word, not the colour." So each row ends in a text pill — Correct / Close / Incorrect — tinted to match the grade buttons the learner already knows.

It's deliberately not the familiarity ○◔◑◕● glyph. Grade (this session) and familiarity (lifetime) are different facts; the spine forbids collapsing them into one mark.

Clearing the selection

Each tally toggles independently. A "Show all" link appears in the state line the moment anything is selected, clearing all three at once, and the line names what you're looking at ("This session · close · incorrect").

Mock caveat: "Show all" is inert here — pure CSS can't uncheck boxes. One line in Vue.

The calm guardrail

FR-18 bans due-counts and backlog walls. This screen clears that bar only because it is session-bounded and opt-in — it exists here, for this session, and is gone when you leave.

Constraint: the mistake count must never escape this screen. No "3 words outstanding" badge on Home, no carry-over into the next session, no nudge. The moment it persists it becomes the debt wall the product is built against.

Replay costs no new endpoint

The drill already holds every card object for the session client-side, so "Practice Again" re-seeds the queue in memory — no words= param on /practice/queue, and it works offline. Direction and scoring mode carry over.

Replay grades count, but cramming can't promote you. A replay Correct earns its point toward re-promotion but never crosses a tier boundary within the replay; Incorrect still drops as normal. So a fix recovers ground without a 30-second-old answer buying a tier.

What this drops from Story 2.7

2.7's AC-2 and AC-3 required the post-session familiarity distribution and "N remain in scope". This design keeps neither — the per-word list is a better answer to "how did I do", and both required a post-session fetch this screen no longer makes.

Decided: 2.7 is rewritten in place (it never reached done/), so those two ACs come out and the ring, list, filters and replay go in.

Density & scroll

Word rows drop to 21px Japanese (the spine's list size is 24px) — a results list is denser than Library. Flagging it as a deliberate deviation for you to accept or reject.

The head block stays put, the list scrolls, the two actions pin to the bottom. A 20-word session never pushes the CTA off-screen.

Decided by default

Row order — the order you met them, replaying the session as lived (not grouped by result; selection already groups on demand).

Rows are not tappable through to Word detail. It's a second exit from a screen whose job is ending the session cleanly. Easy to add later.

A perfect round hides the replay CTA — nothing to run — and "Close" becomes the primary button. No consolation copy, no fake task.
